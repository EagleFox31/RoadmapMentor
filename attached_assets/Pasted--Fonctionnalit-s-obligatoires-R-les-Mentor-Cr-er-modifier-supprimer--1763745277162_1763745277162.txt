📊 Modèle de données (à implémenter)

Propose et implémente un modèle cohérent du type :

- `User`
  - id, full_name, email, role (`MENTOR` / `LEARNER`), hashed_password, created_at

- `Week`
  - id, number, title, start_date, end_date, description, is_validated_by_mentor

- `Objective`
  - id, week_id (FK), type (`CONCEPT`, `ALGO`, `PROJECT`, `OTHER`), title, description, order_index

- `Task`
  - id, objective_id (FK), label, order_index, is_optional (bool)

- `Deliverable`
  - id, week_id (FK), title, description

- `Resource`
  - id, week_id (FK), label, url, resource_type (`DOC`, `VIDEO`, `COURSE`, `ARTICLE`, `OTHER`)

- `TaskProgress`
  - id, task_id (FK), learner_id (FK User), is_done, done_at

- `WeekComment`
  - id, week_id, learner_id, content, created_at

Tu peux ajuster les champs si nécessaire, mais garde cette granularité : semaine → objectifs → tâches, + livrables, + ressources, + progression.

🛠️ API REST à fournir

Implémente des endpoints structurés par router :

**Auth**
- `POST /auth/register` (mentor crée les comptes ou auto-register selon ton choix)
- `POST /auth/login` (retourne un JWT)
- `GET /auth/me`

**Weeks**
- `GET /weeks` : liste de toutes les semaines avec objectifs, tâches, livrables, ressources, et progression pour l’apprenant connecté
- `GET /weeks/{id}`
- `POST /weeks` (mentor)
- `PUT /weeks/{id}` (mentor)
- `DELETE /weeks/{id}` (mentor)
- `POST /weeks/{id}/validate` (mentor valide la semaine)

**Objectives**
- `POST /weeks/{week_id}/objectives` (mentor)
- `PUT /objectives/{id}` (mentor)
- `DELETE /objectives/{id}` (mentor)

**Tasks**
- `POST /objectives/{objective_id}/tasks` (mentor)
- `PUT /tasks/{id}` (mentor)
- `DELETE /tasks/{id}` (mentor)

**Deliverables**
- `POST /weeks/{week_id}/deliverables` (mentor)
- `PUT /deliverables/{id}`
- `DELETE /deliverables/{id}`

**Resources**
- `POST /weeks/{week_id}/resources` (mentor)
- `PUT /resources/{id}`
- `DELETE /resources/{id}`

**Progression**
- `POST /tasks/{task_id}/toggle-progress` (apprenant)
  - Le backend détecte si la progression existe :
    - si oui : bascule `is_done`
    - si non : crée la progression `is_done = true`
- `GET /progress/summary` (pour l’utilisateur connecté)
  - retourne :
    - % de tâches réalisées par semaine
    - % global
    - nombre de tâches réalisées / total

**Commentaires**
- `POST /weeks/{week_id}/comments` (apprenant)
- `GET /weeks/{week_id}/comments`
